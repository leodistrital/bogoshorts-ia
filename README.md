# Universo BOGOSHORTS - Ecosistema Cinematográfico Digital

Portal oficial y concepto interactivo del **Universo BOGOSHORTS**, la plataforma de cortometraje más influyente de América Latina.

## 🌐 Estructura del Proyecto

El sitio web está diseñado en arquitectura limpia multitier con 4 Mundos interconectados y una Agenda audiovisual completa:

- **🏠 Universo (Home Principal):** `index.html` - Hub institucional y portal de entrada a los mundos.
- **🟢 Festival BOGOSHORTS:** `festival/index.html` - Sitio oficial del festival calificador a los Premios Oscar® y Goya. Incluye los componentes **BFM Market** e **IMAGINATÓN**.
- **🔴 Movimiento BOGOSHORTS:** `movimiento/index.html` - Red comunitaria de realización y difusión itinerante 365 días.
- **🟡 BOGOSHORTS Film Agency:** `film-agency/index.html` - Agencia de distribución, ventas internacionales y representación de talentos.
- **🔵 BOGOSHORTS Academy:** `academy/index.html` - Plataforma de laboratorios pedagógicos y formación continua.
- **📅 Agenda General & Programación:** `agenda/index.html` - Calendario unificado de funciones con filtro por mundo, costo de boletería y vista switcher (*Vista Tarjetas vs Modo Calendario por Días*).

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semantic**
- **CSS3 Vanilla (CSS Custom Properties & Responsive Light Theme)**
- **JavaScript Vanilla (ES6+ Interactive Systems & Dynamic Filtering)**

## 🚀 Instalación y Uso Local

No requiere de compiladores ni bundlers. Simplemente abre `index.html` en cualquier navegador web o sirve con un servidor estático:

```bash
# Servidor local sencillo con Python:
python3 -m http.server 8000
```
